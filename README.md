#  VinylFlow - Sistema de Gestión de Vinilos

Sistema local multiusuario desarrollado para la tienda "Sonido Auténtico del Vinilo". Permite a los administradores gestionar el inventario y a los compradores realizar búsquedas y compras simuladas(En un futuro se desarrollara la pasarela de pago).

##  Tecnologías Utilizadas
* **Frontend:** HTML5, CSS3, JavaScript (Vanilla)
* **Backend:** Python 3 (Flask, JWT)
* **Base de Datos:** MySQL 8
